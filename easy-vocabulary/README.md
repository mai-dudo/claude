# Копия easy-vocabulary.com

Точная копия главной страницы https://easy-vocabulary.com: та же разметка, стили, скрипты,
картинки и звуки. Скриншоты оригинала и копии совпадают попиксельно на ширине 1440, 768 и 390 px,
в светлой и тёмной теме.

Работает всё, что есть на главной: заставка с логотипом, мини-игра «Your first three words»
(cat, apple, dog) со звуком, блоки «See it / Hear it / Type it», ввод предложения
«I eat an apple.», растущее дерево, переключатель светлой и тёмной темы, выбор стиля
(«Picture / Easy»), озвучка текста «Playing on your phone?».

## Запуск

Из корня репозитория:

```
python3 -m http.server 8080 --bind 127.0.0.1
```

Затем откройте http://localhost:8080/easy-vocabulary/.

## Чем копия отличается от оригинала

- Кнопки «Start playing», «Choose a game», «Sign in», флаги языков, настройки и ссылка
  в подвале ведут на страницы оригинального сайта: сами игры, аккаунт и база из 11 000 слов
  не копировались.
- Отключён вход в аккаунт: в `game/konto-einstellung.js` пустые адрес и ключ Supabase,
  поэтому страница не обращается к серверу оригинала. Убрана переадресация вошедших
  пользователей на `/game/games.html`.
- Не регистрируется service worker (`/sw.js`), его в копии нет.
- Пути вида `/bilder/…`, `/ton/…`, `/game/…` сделаны относительными, чтобы страница
  работала из папки.

## Права

Тексты, картинки, звуки и код принадлежат авторам easy-vocabulary.com. Копия сделана
для изучения вёрстки; публиковать её как свой сайт под этим названием нельзя.
