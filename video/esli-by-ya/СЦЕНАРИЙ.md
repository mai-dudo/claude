# «Если бы я...» — тексты для озвучки

Ролик примерно на 4:05 (точная длина будет после озвучки). Четыре персонажа, у каждого свой голос.

## Как записать

1. Каждую реплику — отдельным файлом, имя файла = номер реплики: `A1.mp3`, `A2.mp3`, `M1.mp3`… Подойдут mp3, wav, m4a, ogg и голосовые из Telegram.
2. Если удобнее одним файлом на персонажа — тоже можно: читайте реплики по порядку с паузой 2 секунды между ними, я разрежу сам. Назовите файл именем персонажа: `Азиз.mp3`.
3. Цифры уже расписаны словами — читайте как написано. Тише фон, ближе микрофон, без музыки.
4. Темп — спокойный, как будто рассказываете другу. Паузы на тире и многоточиях.
