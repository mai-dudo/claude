# Озвучка

Сюда кладутся файлы с голосами. Подходят mp3, wav, ogg, opus, m4a, aac, flac и голосовые из Telegram.

- **Файл на каждую реплику** — имя файла = номер реплики из `СЦЕНАРИЙ.md`: `I1.mp3`, `A1.mp3`, `M4.ogg`…
- **Или один файл на участника** — `Гутко.mp3`, `Бурханов.mp3`, `Усманов.mp3`, `Тропачев.mp3`: реплики по порядку,
  между ними пауза 1–2 секунды. Скрипт сам разрежет запись по паузам.

Потом `bash tools/build.sh`: ролик подстроится под длину каждой фразы, губы персонажей будут двигаться под голос,
музыка станет тише во время речи.
