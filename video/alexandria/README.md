# «А если знания никогда не исчезали?» — черновой ролик для TikTok

Вертикальный ролик 1080×1920, 30 секунд, 30 к/с, на русском языке. Мысленный эксперимент: Александрийская библиотека не исчезла и развивалась две тысячи лет.

Это черновой вариант (аниматик), а не фотореалистичное видео: всё сделано кодом.
- Графика: 3D-сцены на three.js, покадровый рендер в headless Chromium.
- Озвучка: Silero TTS, голос `eugene`.
- Музыка: партитура в MIDI, звучание из саундфонта FluidR3 GM, плюс синтезированные звуковые эффекты.

Готовые файлы: `alexandria_tiktok.mp4` (видео) и `alexandria_tiktok.srt` (субтитры отдельно, если их нужно наложить в редакторе TikTok).

## Как пересобрать

Что нужно: Node 18+, ffmpeg, fluidsynth и саундфонт `fluid-soundfont-gm`, а также Python-окружение с пакетами `torch`, `numpy`, `scipy`, `omegaconf` и `mido`.

```bash
PYTHON=/path/to/venv/bin/python ./build.sh
```

Отдельные шаги:

```bash
python audio/make_vo.py v4_ru.pt eugene    # озвучка + build/timeline.json + субтитры
python audio/make_music.py                 # музыка и сведение -> build/audio/mix_raw.wav
node render.mjs --preview 1.5,9,20,28      # отдельные кадры в build/preview/
node render.mjs --all --workers 2          # все кадры -> build/video_only.mp4
```

## Что где лежит

- `src/shots/*.js` — сцены: `vault` (тайник), `library` (библиотека), `eras` (эпохи), `table` (стол и лаборатория), `city` (город), `atrium` (атриум и финал).
- `src/schedule.js` — монтажный лист: какая сцена когда в кадре и каким переходом входит.
- `src/main.js` — смешивание сцен, bloom, цветокоррекция, зерно, виньетка.
- `src/overlay.js` — надписи и субтитры.
- `src/textures.js` — процедурные текстуры: пергамент, кожа, камень, мрамор, символ.
- `audio/make_vo.py`, `audio/make_music.py` — озвучка, партитура, звуковой дизайн, сведение.
