# Ролики для TikTok: история, озвучка, анимация

Генератор вертикальных роликов в духе «что будет, если…»: плоская анимация, голос диктора,
крупные субтитры по 1–3 слова с подсвеченными ключевыми словами, плашки-подписи и клиффхэнгер
«часть 2» в конце. Пишете сценарий в JSON — получаете `video.mp4` 1080×1920, обложку и подпись с хэштегами.

Озвучка — бесплатные голоса Microsoft Edge (ключ не нужен), кадры рисуются на canvas в Chromium,
склейка и звук — ffmpeg. Фоновый гул и эффекты (шаги, стук, гул поезда, искры) синтезируются на месте,
чужой музыки в ролике нет.

## Установка

Нужны Python 3.10+ и ffmpeg (`brew install ffmpeg`, `sudo apt install ffmpeg` или с ffmpeg.org).

```
cd tiktok
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
```

## Как сделать ролик

```
python make_video.py stories/metro-tupik.json --stills 13   # по кадру на сцену — проверить картинку (~1 мин)
python make_video.py stories/metro-tupik.json --preview     # посмотреть со звуком в браузере
python make_video.py stories/metro-tupik.json               # готовый ролик (2 мин видео ≈ 5–10 мин рендера)
```

Результат в `out/<slug>/`: `video.mp4`, `cover.jpg`, `post.txt` (название ролика и хэштеги одной строкой — вставить при публикации), `sheet.jpg` (лист кадров).
Ключи: `--draft` — черновик 540×960 и 15 к/с, `--at 3,12.5` — только кадры в эти секунды,
`--workers 4` — сколько вкладок браузера рисуют параллельно (по числу ядер).

Озвучка кэшируется в `.cache/tts`: правка картинки не перезаказывает голос, правка текста — только этой сцены.

## Сценарий

Пример — `stories/metro-tupik.json`. Ролик — список сцен, у каждой текст для диктора `say`
и тип картинки `type`. Длина сцены равна длине фразы.

```json
{
  "title": "Ночь в метро. Часть 1",
  "slug": "metro-tupik-1",
  "voice": "ru-RU-DmitryNeural", "rate": "+12%", "pitch": "-4Hz",
  "hero": { "hat": "hair", "jacket": "#2a9d8f", "backpack": "#e76f51", "light": "phone" },
  "post": { "caption": "Название ролика", "hashtags": ["#метро", "#страшныеистории", "#истории"] },
  "scenes": [
    {
      "type": "tunnel",
      "say": "Первое — [рельс]. Сбоку идёт третий, [контактный]. На нём {825 вольт}.",
      "chip": { "text": "Правило 1. Рельс", "color": "yellow" },
      "rail": "контактный",
      "big": { "text": "825 В", "at": "825" },
      "sfx": [{ "type": "zap", "at": "825" }]
    }
  ]
}
```

- `[слово]` в тексте — жёлтая подсветка в субтитрах, `{слово}` — красная. В голос скобки не попадают.
- Время любого события (`at`, `from`, `until`, `rail`, `lightsOff`…) задаётся словом из текста сцены —
  событие случится, когда диктор его произнесёт. Можно со сдвигом: `"гул+0.5"`. Число — секунды от начала
  сцены, отрицательное — от конца.
- Голоса: `ru-RU-DmitryNeural` (мужской), `ru-RU-SvetlanaNeural` (женский). `rate` — темп, `pitch` — высота.
- `pause` — пауза после каждой сцены (по умолчанию 0,3 с), у сцены можно задать свою `pause` или `dur`.
- `music` — путь к своему треку (зациклится тихо под голосом), `musicDb` — громкость; `ambient: "none"` убирает гул.

### Плашки и эффекты (в любой сцене)

| Поле | Что это |
| --- | --- |
| `chip: { text, color }` | плашка наверху (`red`, `green`, `yellow`, `white`, `blue`, `dark`) |
| `tags: [{ text, x, y, at, to: [x, y] }]` | подпись в рамке у предмета, `to` — пунктир к точке |
| `stamp: { text, at }` | наклонная красная наклейка («НИКАКОГО ОГНЯ») |
| `big: { text, sub, at, y, count: [от, до], until }` | огромная светящаяся цифра; с `count` число отсчитывается, `text` дописывается после |
| `cards: [{ label, value, color, at }]` | карточки с цифрами наверху («−30…+40») |
| `meters: [{ label, value: [от, до], text, at }]` | полоски-шкалы, значения 0…1 |
| `timer: { from, to, at }` | табло обратного отсчёта, секунды |
| `cam: { zoom: [1, 1.2], focus: [x, y], punch, shake }` | наезд камеры к точке, тряска |
| `sfx: [{ type, at, db }]` | `hit`, `whoosh`, `knock`, `steps`, `zap`, `rumble`, `beep`, `click`, `drip`, `wind`, `powerdown` (гаснет свет), `static` (шипение радио), `water` (вода из крана), `fire` (треск огня) |
| `fade` | появление из чёрного |

Кадр 1080×1920, координаты в пикселях. Субтитры на высоте `captionY` (1400). Нижнюю четверть кадра
и правый край в TikTok закрывают подпись и кнопки — важное туда не ставьте.

### Сцены

| `type` | Что рисует | Основные поля |
| --- | --- | --- |
| `wagon` | вагон метро изнутри | `lights` (`on`/`off`/`flicker`), `lightsOff`, `handle`, `hero { x, pose: sleep/sit/stand, light }` |
| `tunnel` | тоннель в разрезе (`style`: `metro` или кирпичный `brick`) | `dark` 0…1, `rail`, `train`, `loco`, `niche`, `signal`, `figure`, `phantoms`, `fog`, `water`, `surface`, `tint`, `people`, `lights`, `pickets: [{ x, text, at }]`, `wind` |
| `city` | ночной город | `metro` (павильон «М»), `cutaway` (разрез: эскалатор, станция, тупик), `dawn` (рассвет), `danger`, `rain`, `snow` (снег и заснеженный двор), `blackout` (дома гаснут; `0` — уже темно), `flash` (вспышка на подстанции), `figures { n, kind: people/zombie }`, `hero`, `people` |
| `phone` | экран телефона | `time`, `date`, `battery`, `net`, `notes: [{ title, text, at }]`, `call { name, at, ring }` — экран звонка |
| `map` | схема линии метро | `stations: [{ name, pos }]`, `deadEnd`, `marker { pos, label }`, `measure { a, b, text }` |
| `note` | записи в тетради при свете фонаря | `title`, `lines: [{ text, at, color, strike }]` |
| `cave` | пещера в разрезе | `water` (0…1 или `[от, до]` — вода поднимается), `murk`, `dark`, `ledge`, `squeeze`, `drips`, `hole`, `guide`, `crowd { n, x0, x1, who, pose }`, `stretcher`, `surface`, `lights` |
| `mountain` | гора со входом в пещеру | `time` (`day`/`dusk`/`night`), `rain`, `lightning`, `bikes`, `sign: ["строка", …]`, `camp`, `statue` |
| `board` | доска почёта с фотографиями | `who` (кто из `cast` на выделенном фото), `focus` (номер рамки 0…5), `caption`, `at` |
| `card` | титр, конец серии | `kicker`, `title: ["строка", { text, color }]`, `sub` |
| `blank` | пустой фон под плашки | `bg` |
| `room` | комната с окном, кроватью и зеркалом | `time` (`night`/`morning`), `mirror` (`loki` — в отражении рогатый шлем, `empty`, `false` — шкаф), `mirrorAt`, `portal { at, x }`, `blackout`, `frost { at, until }` (иней на стекле), `blanket` (окно завешивают одеялом), `dark`, `people` |
| `timeline` | светящаяся временная линия | `reveal`, `branches: [{ at, from, dir, color: orange/green, grown, prune, glowAt }]` |
| `void` | Пустота на краю времени: руины и брошенная машина | `alioth { at, rise }` — фиолетовая грозовая туча, `alligators: [{ x, scale, facing, at }]`, `magic` (у героя светятся руки), `people` |
| `myth` | северное сияние и восьминогий конь | `walk: [x0, x1]`, `legs`, `scale` |
| `kitchen` | кухня: холодильник, кран, чайник с розеткой, плита, окно | `time` (`night`/`day`), `blackout`, `tap { at, until }`, `pot: "full"`, `bottles: [{ at }]`, `unplug`, `spark`, `candle`, `candleOff`, `fire { at, until }` (горит штора), `gas`, `co` (угарный газ), `radio`, `fridge { open }`, `dark`, `hero`, `people` |
| `block` | многоэтажка в разрезе: квартиры, стояк с водой, насос в подвале, лифт | `floors`, `blackout`, `pumpOff` (насос встаёт, вода уходит с верхних этажей), `dryTo`, `lift` |
| `tower` | вышка сотовой связи и индикатор её аккумулятора | `drain { at, until }` — заряд падает до нуля, потом вышка молчит |
| `shop` | магазин без света: вывеска, витрина, дверь, банкомат | `time`, `sign` (на двери «только наличные»), `atm`, `queue` (сколько людей в очереди), `dark` |
| `kit` | карточки «что держать дома» с галочками | `title`, `titleAt`, `items: [{ icon: water/food/torch/power/radio/cash/meds, text, at }]` |

Герой: `hero` на верхнем уровне — внешность (`hat`: `hair`/`helmet`/`cap`/`none`/`horns` — шлем с рогами длиной `horns`, `hair`, `skin`, `jacket`,
`stripes`, `pants`, `backpack`, `light`: `phone`/`torch`); `hero` в сцене — где он и что делает:
`x`, `walk: [x0, x1]` с `from`/`until`, `pose`, `light`, `lightOff`, `then: { at, …что поменять }`.
`"hero": false` — героя в сцене нет.

Другие персонажи описываются в `cast` на верхнем уровне (`"cast": { "ded": { "hat": "helmet", … } }`) и выводятся
в сцене списком `people: [{ "who": "ded", "walk": [100, 700] }]` с теми же полями, что у героя;
`"dead": true` — фонарь в руке не светит. В сценах `room` и `void` у персонажей ещё есть `ghost: true` (иллюзия),
`enter` (выходит из портала в это слово) и `vanish` (исчезает со вспышкой). Позы: `stand`, `walk`, `sit`, `sleep`, `swim` (плывёт), `lie` (лежит);
`diver: true` — баллон и маска, `mask: true` — только маска, `light: "head"` — фонарь на каске, `dig` — машет руками
у стены, `carry` — руки вперёд, `eyesClosed`. У пловца задаётся `y`. Примеры — `stories/metro-tupik-2.json` и `stories/tham-luang-1.json`.
Новые сцены добавляются в `render/scenes.js` (фэнтези-сцены — в `render/fantasy.js`, сцены о выживании — в `render/survival.js`).
В `kitchen`, `shop` и в `blackout` время `0` (например, `"unplug": 0` или бутылки с `"at": 0`) значит «уже случилось
до сцены» — без анимации появления.
Пример ролика на этих сценах — `stories/blackout-1.json`.

## Рисованные ролики

Вместо плоской графики сцена `art` показывает готовую иллюстрацию и оживляет её: наезд или панорама камеры,
пыль, дождь, туман, мерцание, зерно плёнки, свет телефона. Пример — `stories/metro-art-1.json`: тот же текст,
что у первой серии про метро, но у сцен вместо координат описание кадра `draw` и герои `who`.

```
python make_art.py stories/metro-art-1.json --done 01a          # out/metro-art-1/chatgpt.txt — все кадры одним сообщением
python make_art.py stories/metro-art-1.json --add ~/Downloads/*.png   # разложить картинки по кадрам по порядку
python make_art.py stories/metro-art-1.json --api               # или нарисовать через OpenAI API (ключ OPENAI_API_KEY)
python make_video.py stories/metro-art-1.json
```

Картинки лежат в `art/<slug>/` (01.jpg, 01a.jpg, 01b.jpg …). Пока какой-то нет, в ролике на её месте заглушка
с описанием кадра. Поля сцены `art`: `move` (`in`, `out`, `left`, `right`, `up`, `down`, `drift`), `focus` [x, y] в долях
картинки, `fx` (`grain`, `vignette`, `dust`, `rain`, `fog`, `flicker`, `phantoms`, `sparks`, `embers`, `snow`),
`glows` [{ x, y, r, color, pulse, at }] — свет в долях картинки, `dim` { at, amount } — свет гаснет,
`fit` (`cover`, `letterbox`, `blur`), `images` [{ draw, who, at }] — несколько кадров в одной сцене со сменой на слове.
На верхнем уровне сценария: `style` — описание стиля для всех картинок, `cast.<имя>.look` — внешность героя.

## Голос ElevenLabs

Живой голос вместо бесплатного: ключ ElevenLabs в переменной `ELEVENLABS_API_KEY` и голос в сценарии:

```json
"tts": "elevenlabs", "voiceId": "…", "voiceModel": "eleven_multilingual_v2",
"voiceSettings": { "stability": 0.45, "style": 0.15, "speed": 1.0 }
```

`python voice.py voices` покажет ваши голоса и популярные русские голоса из библиотеки ElevenLabs. Любой ролик
можно переозвучить без правки сценария: `python make_video.py stories/… --tts elevenlabs --voice-id …`.
ElevenLabs отдаёт время каждой буквы, поэтому субтитры совпадают с голосом так же точно. Без ключа
ролик озвучивается бесплатным голосом с предупреждением. На бесплатном тарифе ElevenLabs через API работают
только стандартные (англоязычные) голоса; голоса из библиотеки, в том числе русские, требуют платного баланса.

## Своя озвучка

Озвучили текст сами (своим голосом или в любой нейросети)? Дайте файл: `python make_video.py stories/… --narration озвучка.mp3`
или `"narration": "путь/к/файлу"` в сценарии. Текст для записи — `out/<slug>/text.txt` (абзац на сцену). Движок распознает
речь, сопоставит её со сценарием, разрежет запись посередине пауз между сценами и сделает субтитры по словам.
Небольшие отступления от текста не страшны. Нужен `faster-whisper`.

## Голос Fish Audio

`"tts": "fish"`, `"voiceId"` — id голоса из адреса `fish.audio/m/<id>`, ключ в переменной `FISH_API_KEY`,
модель — `voiceModel` (по умолчанию `s2.1-pro-free`). Fish Audio не отдаёт тайминги слов, поэтому их находит
распознавание речи (нужен `pip install faster-whisper`): точность — в пределах пары десятых секунды.

## Как писать истории, которые смотрят

1. Первая фраза — крючок с запретом или парадоксом: «Если …, {не делай} вот это».
2. Герой с именем и профессией, конкретные цифры («60 килограммов», «825 вольт»), правило «три пункта».
3. Каждые 5–8 секунд — новая картинка или новая плашка.
4. Конец — загадка без ответа и титр «часть 2». Следующая серия начинается с повтора загадки.
5. Длина 1–2,5 минуты, как у роликов, на которые мы ориентируемся.

Новую историю удобно попросить у Claude: «Напиши сценарий в формате `tiktok/stories/metro-tupik.json`
про … — 10–13 сцен, только существующие типы сцен, факты проверяемые».
Факты в истории должны быть правдой: за опасные советы TikTok режет охваты, а зрители — доверие.

## Публикация в TikTok

Проще всего — вручную с телефона: перекиньте `video.mp4` на телефон, загрузите, вставьте текст из `post.txt`,
обложку выберите из кадра. В приложении можно подложить трендовый звук на 3–5 % громкости — это помогает охвату.
Голос синтезирован, поэтому надёжнее включить при публикации метку «Создано ИИ» (AI-generated content).

Автопубликация возможна через официальный Content Posting API, но нужен свой аккаунт разработчика
TikTok и приложение. Пока приложение не прошло аудит TikTok, всё опубликованное через API видно только
автору (приватно). Другой путь — загрузка в черновики: ролик приходит во «Входящие» TikTok, и вы публикуете его в приложении;
для этого приложению нужен одобренный доступ `video.upload`, про аудит документация в этом случае не пишет.
Ещё вариант — сервисы отложенного постинга с поддержкой TikTok (Buffer, Metricool и т. п.).
