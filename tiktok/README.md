# Ролики для TikTok: история, озвучка, анимация

Генератор вертикальных роликов в духе «что будет, если…»: плоская анимация, голос диктора,
крупные субтитры по 1–3 слова с подсвеченными ключевыми словами, плашки-подписи и клиффхэнгер
«часть 2» в конце. Пишете сценарий в JSON — получаете `video.mp4` 1080×1920, обложку и подпись с хэштегами.

Озвучка — бесплатные голоса Microsoft Edge (ключ не нужен), кадры рисуются на canvas в Chromium,
склейка и звук — ffmpeg. Фоновый гул и эффекты (шаги, стук, гул поезда, искры) синтезируются на месте,
чужой музыки в ролике нет.

## Установка

Нужны Python 3.10+ и ffmpeg (`brew install ffmpeg`, `sudo apt install ffmpeg` или с ffmpeg.org).

```
cd tiktok
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
```

## Как сделать ролик

```
python make_video.py stories/metro-tupik.json --stills 13   # по кадру на сцену — проверить картинку (~1 мин)
python make_video.py stories/metro-tupik.json --preview     # посмотреть со звуком в браузере
python make_video.py stories/metro-tupik.json               # готовый ролик (2 мин видео ≈ 5–10 мин рендера)
```

Результат в `out/<slug>/`: `video.mp4`, `cover.jpg`, `post.txt` (подпись и хэштеги), `sheet.jpg` (лист кадров).
Ключи: `--draft` — черновик 540×960 и 15 к/с, `--at 3,12.5` — только кадры в эти секунды,
`--workers 4` — сколько вкладок браузера рисуют параллельно (по числу ядер).

Озвучка кэшируется в `.cache/tts`: правка картинки не перезаказывает голос, правка текста — только этой сцены.

## Сценарий

Пример — `stories/metro-tupik.json`. Ролик — список сцен, у каждой текст для диктора `say`
и тип картинки `type`. Длина сцены равна длине фразы.

```json
{
  "title": "Ночь в метро. Часть 1",
  "slug": "metro-tupik-1",
  "voice": "ru-RU-DmitryNeural", "rate": "+12%", "pitch": "-4Hz",
  "hero": { "hat": "hair", "jacket": "#2a9d8f", "backpack": "#e76f51", "light": "phone" },
  "post": { "caption": "Подпись к ролику", "hashtags": ["#метро", "#истории"] },
  "scenes": [
    {
      "type": "tunnel",
      "say": "Первое — [рельс]. Сбоку идёт третий, [контактный]. На нём {825 вольт}.",
      "chip": { "text": "Правило 1. Рельс", "color": "yellow" },
      "rail": "контактный",
      "big": { "text": "825 В", "at": "825" },
      "sfx": [{ "type": "zap", "at": "825" }]
    }
  ]
}
```

- `[слово]` в тексте — жёлтая подсветка в субтитрах, `{слово}` — красная. В голос скобки не попадают.
- Время любого события (`at`, `from`, `until`, `rail`, `lightsOff`…) задаётся словом из текста сцены —
  событие случится, когда диктор его произнесёт. Можно со сдвигом: `"гул+0.5"`. Число — секунды от начала
  сцены, отрицательное — от конца.
- Голоса: `ru-RU-DmitryNeural` (мужской), `ru-RU-SvetlanaNeural` (женский). `rate` — темп, `pitch` — высота.
- `pause` — пауза после каждой сцены (по умолчанию 0,3 с), у сцены можно задать свою `pause` или `dur`.
- `music` — путь к своему треку (зациклится тихо под голосом), `musicDb` — громкость; `ambient: "none"` убирает гул.

### Плашки и эффекты (в любой сцене)

| Поле | Что это |
| --- | --- |
| `chip: { text, color }` | плашка наверху (`red`, `green`, `yellow`, `white`, `blue`, `dark`) |
| `tags: [{ text, x, y, at, to: [x, y] }]` | подпись в рамке у предмета, `to` — пунктир к точке |
| `stamp: { text, at }` | наклонная красная наклейка («НИКАКОГО ОГНЯ») |
| `big: { text, sub, at, y }` | огромная светящаяся цифра |
| `cards: [{ label, value, color, at }]` | карточки с цифрами наверху («−30…+40») |
| `meters: [{ label, value: [от, до], text, at }]` | полоски-шкалы, значения 0…1 |
| `timer: { from, to, at }` | табло обратного отсчёта, секунды |
| `cam: { zoom: [1, 1.2], focus: [x, y], punch, shake }` | наезд камеры к точке, тряска |
| `sfx: [{ type, at, db }]` | `hit`, `whoosh`, `knock`, `steps`, `zap`, `rumble`, `beep`, `click`, `drip` |
| `fade` | появление из чёрного |

Кадр 1080×1920, координаты в пикселях. Субтитры на высоте `captionY` (1400). Нижнюю четверть кадра
и правый край в TikTok закрывают подпись и кнопки — важное туда не ставьте.

### Сцены

| `type` | Что рисует | Основные поля |
| --- | --- | --- |
| `wagon` | вагон метро изнутри | `lights` (`on`/`off`/`flicker`), `lightsOff`, `handle`, `hero { x, pose: sleep/sit/stand, light }` |
| `tunnel` | тоннель в разрезе (`style`: `metro` или кирпичный `brick`) | `dark` 0…1, `rail`, `train`, `loco`, `niche`, `signal`, `figure`, `phantoms`, `fog`, `water`, `surface`, `tint` |
| `city` | ночной город | `metro` (павильон «М»), `cutaway` (разрез: эскалатор, станция, тупик), `danger`, `rain`, `figures { n, kind: people/zombie }` |
| `phone` | экран телефона | `time`, `date`, `battery`, `net`, `notes: [{ title, text, at }]` |
| `map` | схема линии метро | `stations: [{ name, pos }]`, `deadEnd`, `marker { pos, label }`, `measure { a, b, text }` |
| `note` | записи в тетради при свете фонаря | `title`, `lines: [{ text, at, color, strike }]` |
| `card` | титр, конец серии | `kicker`, `title: ["строка", { text, color }]`, `sub` |
| `blank` | пустой фон под плашки | `bg` |

Герой: `hero` на верхнем уровне — внешность (`hat`: `hair`/`helmet`/`cap`/`none`, `hair`, `skin`, `jacket`,
`stripes`, `pants`, `backpack`, `light`: `phone`/`torch`); `hero` в сцене — где он и что делает:
`x`, `walk: [x0, x1]` с `from`/`until`, `pose`, `light`, `lightOff`, `then: { at, …что поменять }`.
`"hero": false` — героя в сцене нет. Новые сцены добавляются в `render/scenes.js`.

## Как писать истории, которые смотрят

1. Первая фраза — крючок с запретом или парадоксом: «Если …, {не делай} вот это».
2. Герой с именем и профессией, конкретные цифры («60 килограммов», «825 вольт»), правило «три пункта».
3. Каждые 5–8 секунд — новая картинка или новая плашка.
4. Конец — загадка без ответа и титр «часть 2». Следующая серия начинается с повтора загадки.
5. Длина 1–2,5 минуты, как у роликов, на которые мы ориентируемся.

Новую историю удобно попросить у Claude: «Напиши сценарий в формате `tiktok/stories/metro-tupik.json`
про … — 10–13 сцен, только существующие типы сцен, факты проверяемые».
Факты в истории должны быть правдой: за опасные советы TikTok режет охваты, а зрители — доверие.

## Публикация в TikTok

Проще всего — вручную с телефона: перекиньте `video.mp4` на телефон, загрузите, вставьте текст из `post.txt`,
обложку выберите из кадра. В приложении можно подложить трендовый звук на 3–5 % громкости — это помогает охвату.
Голос синтезирован, поэтому надёжнее включить при публикации метку «Создано ИИ» (AI-generated content).

Автопубликация возможна через официальный Content Posting API, но нужен свой аккаунт разработчика
TikTok и приложение. Пока приложение не прошло аудит TikTok, всё опубликованное через API видно только
автору (приватно). Другой путь — загрузка в черновики: ролик приходит во «Входящие» TikTok, и вы публикуете его в приложении;
для этого приложению нужен одобренный доступ `video.upload`, про аудит документация в этом случае не пишет.
Ещё вариант — сервисы отложенного постинга с поддержкой TikTok (Buffer, Metricool и т. п.).
