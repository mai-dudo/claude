# Barricade (Malefiz)

Браузерная версия классической настольной игры Barricade. Без сборки и зависимостей:
откройте `index.html` в браузере — и можно играть.

## Возможности

- 2–4 игрока за одним экраном, любой из них может быть компьютером.
- Режим «демо»: четыре компьютерных игрока играют между собой.
- Подсветка доступных фишек и клеток, отдельная подсветка сбития и снятия баррикады.
- Журнал ходов и встроенная справка по правилам.

## Правила

1. У каждого игрока пять фишек в базе. Побеждает тот, кто первым доведёт одну фишку до цели наверху доски.
2. Бросьте кубик и передвиньте одну фишку ровно на выпавшее число клеток, не возвращаясь на уже пройденные клетки. Если ход возможен, его обязательно нужно сделать.
3. Через фишки можно перепрыгивать. Встать на свою фишку нельзя; фишка соперника, на которой закончился ход, отправляется в базу.
4. Баррикады нельзя проходить и перепрыгивать. Остановившись ровно на баррикаде, игрок снимает её и ставит на любую свободную клетку, кроме цели, нижней линии и стартовых дорожек.
5. На цель нужно попасть точным броском.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка экранов настройки и игры |
| `style.css` | Оформление |
| `engine.js` | Правила игры и компьютерный игрок (работает и в браузере, и в Node) |
| `ui.js` | Отрисовка доски на SVG и обработка действий |
| `test.js` | Проверка движка: правила ходов и симуляция партий |

## Проверка движка

```
node test.js
```
