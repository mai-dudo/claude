# Barricade

Браузерная игра в стиле Quoridor: поле 9×9, у каждого игрока фишка и 10 стен.
Побеждает тот, кто первым доведёт фишку до противоположного края.

Всё в одном файле — откройте `barricade.html` в браузере (удобно и на телефоне).

## Режимы

- Против компьютера.
- Локальная партия: двое за одним экраном.
- Смотреть: компьютер против компьютера.

## Управление

- Коснитесь подсвеченной клетки, чтобы сходить фишкой.
- Нажмите «Горизонтально» или «Вертикально», затем коснитесь зазора между клетками, чтобы поставить стену.
- «Отменить» откатывает ход, «Сбросить» начинает партию заново.
