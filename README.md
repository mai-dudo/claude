# Striver — личная страница

Статический сайт из одного файла `index.html` (стиль Frutiger Aero / y2k).

Открыть локально: просто открыть `index.html` в браузере или запустить
`python3 -m http.server 8080` и зайти на http://localhost:8080.

Ссылки на соцсети в `index.html` помечены `#` — их нужно заменить реальными.
